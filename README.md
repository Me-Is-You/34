## 一句话原理

两份文件的字节流 `a[i]`、`b[i]` 经**秩配对**（rank-pairing）形成 `N` 个量子比特对。
每个字节被映射到布洛赫球上的态：

```
|ψ(x)⟩ = cos(φ_x)|0⟩ + sin(φ_x)|1⟩,   φ_x = π·x / 510 ∈ [0, π/2]
```

对 B 侧施加纠缠门 `U(θ)` 后，每对态的**并发度**（concurrence）为

```
C(θ) = 2|αδ − βγ|
α = cosφa·cosφb      β = cosφa·sinφb·cosθ + sinφa·cosφb·sinθ
δ = sinφa·sinφb      γ = sinφa·cosφb·cosθ − cosφa·sinφb·sinθ
```

单轮 Procrustean 浓缩成功概率 `p = 1 − √(1 − C²)`；
多轮蒸馏中第 `r` 轮成功率按保真度 `d` 衰减为 `p·d^r`，纠缠对最终被提纯为
贝尔对的概率为 `1 − Π_{r=1..R}(1 − p·d^r)`。
于是**纠缠浓度**定义为：

```
conc(θ, R) = mean_i [ 1 − Π_{r=1..R}(1 − p_i·d^r) ]
```

## 深层优化与 34% 定律

**优化问题**（硬约束！）：

```
maximize   U(θ, R) = conc(θ, R) − 0.02·R     （蒸馏轮数也要成本）
subject to conc(θ, R) ≥ 34%                   ← 阿雷纳常数，不可违反
           0.05 ≤ θ ≤ π/2,  1 ≤ R ≤ 64
```

采用**可行域内的模拟退火**：

- 从最高浓度点 `(θ = π/2, R = 64)` 出发（养成模型提供先验时热启动）；
- 每次只接受 `conc ≥ 34%` 的候选状态——**不可行状态一律拒绝**，
  因此优化轨迹上的每一个点都不低于 34%（不是只有最终结果合格）；
- 目标函数同时惩罚过大的 `R`，逼出"用最少蒸馏轮数保住浓度下限"的最优解。

为了加速，退火过程在确定性 mini-batch（16384 对）上评估目标；
最终浓度在**全量数据**上重算，若样本偏差导致略低于 34%，则按浓度对 `R`
的单调性二分补足轮次——34% 在任何情况下都守得住。

**数学上无法纠缠的文件**（例如全零字节 = 全 `|0⟩` 态）会被诚实拒绝并报错，
不会伪造结果。这就是"真实"。

## 深度趋于 99.99%

深度模式（`--depth-rounds <R>`，默认 16384）在理想保真极限 `d → 1` 下，
每对经 `R` 轮提纯为贝尔对的概率为：

```
s_i = 1 − (1 − p_i)^R
```

然后按 `s` 降序做 **Procrustean 选择**——取"最大可行子集"使其平均深度
达到 99.99%：

```
netDepth（净深度） = 所选子集的平均 s_i     → 趋于 99.99%
rawDepth（原始深度）= 全体对的平均 s_i      → 如实披露，不做假
selFrac（选择比例） = 所选对数 / 总对数      → 选择代价透明公开
```

- 若数学上不可达（`s_max < 99.99%`），**诚实拒绝输出**（可证伪性）；
- `verify` 独立重算净深度并复核 `≥ 99.99%`。

## 持续运行巡回环境（tour · 自研自愈）

```bash
./entangle tour --in inbox --out out --journal journal.log --model model.txt --poll 5
```

`tour` 是**真实发射巡回环境**下的守护进程：

- 轮询 `inbox`，新到的 PDF 自动**两两配对纠缠**（或 `--pair-with` 固定配对）；
- 每份产物写出后立即**自检**（12 项验证），失败自动重算（自愈）；
- **失败重试**：纠缠失败按指数退避重试（最多 3 次）；
- **崩溃恢复**：重启时从 `journal.log` 恢复已处理输入，绝不重复纠缠，
  输出序号继续编号；
- **损坏自愈**：启动时扫描输出目录，验证失败的产物按 journal 记录重算修复；
- **养成更新**：每次成功运行把最优参数写回 `model.txt`（EMA 在线学习）；
- 优雅停机：`Ctrl-C` / `SIGTERM`，journal 完整落盘。

## EPR 关联共享（联合测量）

两份 share 由**确定性 PRF**（splitmix64）生成的共享密钥串接而成：

```
K[r] = PRF(seed, r)                     （8 bit / 对）
shareA[permA[r]] = a[permA[r]] ⊕ K[r]
shareB[permB[r]] = b[permB[r]] ⊕ K[r]
```

- **单边测量**：`shareA` / `shareB` 的熵 ≈ 8 bit/字节 → 与随机噪声不可分辨；
- **联合测量**：`shareA[i] ⊕ shareB[配对位]` 精确等于 `a[i] ⊕ b[i]`
  （验证器逐字节复核）；
- **互信息** `I(shareA; shareB)` ≈ 6.6 bit/字节——关联只存在于联合测量之中。

### 诚实的物理边界：为什么 CHSH S ≤ 2

经典信道模拟量子通道 ⇒ 共享密钥 `K` 就是**局域隐变量**（LHV）。
密钥把比特级交叉关联完全洗白，CHSH 分数恒在经典界内。
**真正的 S > 2 需要量子硬件**。本程序不作假，这正是
《经典信道模拟量子通道》这篇论文的观点——经典就是经典，模拟就是模拟，
但模拟得真实。

## verify —— 12 项真实性检验

```bash
./entangle verify entangled.pdf shareA.bin shareB.bin
```

1. PDF 结构有效（%PDF + xref + trailer）
2. 叠加态容器内含 2 份 PDF
3. 纠缠参数已记录（seed/theta/rounds）
4. 嵌入文件 A 完整性（SHA-256，与记录一致）
5. 嵌入文件 B 完整性（SHA-256，与记录一致）
6. 嵌入文件长度与记录一致
7. shareA.bin / shareB.bin 可读
8. share 长度 == 原文件长度
9. EPR 共享密钥关联（K 逐字节可复现，覆盖全部存储位）
10. share 为不可区分噪声（有限样本修正熵 ≥ 阈值）
11. 纠缠浓度值 ≥ 34%（阿雷纳常数，独立重算）
12. 净纠缠深度 ≥ 99.99%（趋于，独立重算）

篡改任何一份 share、嵌入文件或参数记录，验证即失败（退出码非 0）。

## FAQ

**Q：这是"真"纠缠吗？**
A：是数学意义上的真实：浓度、并发度、互信息、EPR 关联、深度全部可独立重算，
验证器 12 项全绿、审计十项全过。但它同时也是**经典信道对量子通道的模拟**——
这正是仓库里那份 PDF 的论点。真量子超越需要硬件，我们不撒谎。

**Q：深度 99.99% 是"全部"吗？**
A：不是。净深度 99.99% 是在 Procrustean 选择后的子集上成立（本仓库 94.88% 的对）。
原始深度 96.53% 如实披露，选择比例透明公开——这才是诚实的 99.99%。

**Q：为什么用 C/C++？**
A：因为 `-O2` 编译出的机器码跑模拟退火比 Python 快两个数量级
（本演示不到 1 秒跑完全量 285385 对的优化 + 蒸馏 + 深度）。Rust 是 C++ 的
"波函数坍缩版本"，汇编是它的狄拉克记号，Verilog 是它在 FPGA 上的
投影——本仓库忠于 C++，哲学上兼容全部。

**Q：浓度值能低于 34% 吗？**
A：不能。命令行传 `--min-conc 0.20` 也会被自动提升到 34%。
阿雷纳常数守恒。

**Q：tour 在手机上能跑吗？**
A：能。Termux 里 `./entangle tour --in ~/storage/shared/Download --out out --poll 10`，
把 PDF 丢进 Download 目录即可持续纠缠。详见 `TERMUX.md`。

**Q：两份同样大小的文件会怎样？**
A：长度不同时，短的一方按周期填充参与配对；EPR 密钥只作用于
"存储位"，验证器按存储位逐字节复核，不依赖对侧长度。
